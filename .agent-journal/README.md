# Agent journal

Working notes of agents: what a session decided with the human, and why, so the next agent can pick up. Not documentation — design docs hold the current state; this holds the trail (AGENTS.md rule 4).

- One file per session: `YYYY-MM-DD-<task>-<topic>.md`, e.g. `2026-10-21-M3.2-home-driver.md`.
- Content: the task, decisions (one line each, with the reason), what was edited, what is left.
- Never edit another session's file. Never cite or link the journal from docs or code.
