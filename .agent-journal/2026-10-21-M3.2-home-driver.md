# 2026-10-21 — M3.2 Home driver: per-origin device specifics

Role: system designer & architect. Docs only.

## Decisions (by Tomas)

- Driver renamed `hacomposite` → `home`: `driver-home`, `type: home`, kinds `home.*`, `home-template`, `home-rule`. HA composite API → Home API, HA control UI → Home UI. "Composite" described how it's built, not what it is.
- Tails `local`/`matter`: one per-driver counter, never reused (`device.local.17`). Derived tails break on source change and collide on Matter endpoint renumbering.
- Matter mapping: one table, code in `driver-home/matter-map`, design in 16a; everything that needs it imports it.
- Matter binding: SET replies after ack, stores the target at once (general rule, as DALI 12 §10); per-type details go to 12c (M3.3). No session/timeout → unreachable, status error → bad-payload, null → not reachable. `optionalBound` snapshot because records bind before the node connects. Name/labels/product copied once at commissioning, never written back.
- `info.product` (vendor, name, serial) for every origin.
- Remote: import every `exposed` device of any origin; loops and duplicates are the admin's. `evokNodeVersion` range in code; WS API hello advertises it. SET name/userLabels forwarded.
- `exposed` (leaves the PLC) split from `controllable` (Home UI control). On remote devices both overridable locally; `controllable` override can only disable.
- Remote groupId ignored; local `overrides.groupId`; a remote's level/room/group can be attached as a read-only mirror; attached group wins over the override.
- Management on `manage.<method>`; Home API relays a subset, no `listDevices` (introspection + `listHierarchy` with members suffice).

## Forms and refs (same session, later)

- `OptionSpec` folded into `ValueSchema`: `Annotations` (`label`, `hint`, `default`, `optional`) on every schema, plus `enumLabels` and `ref` in `Semantics`. One schema system for wire values and human forms.
- `{ type: 'void' }` kept (Tomas preferred it over "omitted"); template `settings` optional instead of `Codecs.void`.
- `Codecs.optional()` kept despite the name clash with field `optional()` — different namespaces.
- Localization at the edge (WS API per-connection plugin); drivers send every language so introspection stays shared. Formats `text` and `schema` let the edge find text inside values.
- Refs are owned by the consuming driver (Tomas): it lists and validates, only the id is stored. `$refs` is the fifth reserved tail; `has` is internal, defaults to "in `list`". No hierarchy ref types — `listHierarchy` exists. Client-side `address` ref dropped; `home.source` from `config.local` instead.
- Remotes stay in KV; `config.local` lists the drivers templates may use.
- One `form` per template/rule kind, built by the driver; UI renders form + the method's static `argsSchema`.
- Roles = `Selection` like slots: several kinds, several sources; one physical device only; reachable = all; unreachable, no rollback.
- `manage` = one device `home.Manage`, methods as fields, one args struct each.
