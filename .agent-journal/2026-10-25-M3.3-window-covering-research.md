# 2026-10-25 — M3.3 research: WindowCovering

Role: researcher. Writes only under `research/`.

## Decisions (Tomas)

- Two relays (up, down), no feedback; the cover tilts first, then travels; per-cover up, down and tilt times.
- Safety buffer at both ends; reset to a known end (full up / full down), because time counting drifts.
- A positioning move goes to the lift position first, then tilts.
- One template for now: two relays.
- Wind level 1: down + slats closed ⇒ tilt open, tilt refused. Level 2: up, down refused. Source: almanac first, hardware sensor later.
- Wind reaction is the device's safety function, built in: template = 2 relays + wind/gust source role. Levels in device settings, with an override.
- Reaction to an unreachable wind source and to the wind dropping: settings.
- `upMs`/`downMs` measured end to end, tilt included; tilt measured alone.
- `upMs`, `downMs`, `tiltMs` are device settings.
- No override; instead `protection`: none | level1 | level2 | both — which levels act. Permanent, set in Inspector UI.
- Level 2 = CLIMAX class speed; level 1 below it. Widths/heights/guides set by Tomas at commissioning — not researched further.
- Covers: CLIMAX, C type — taken as C-80 (to confirm). Added 06 §4.5 (CLIMAX classes) and §4.6 (gust vs mean); P3, P6 rewritten.
