## Decisions with Tomas

- Nuxt UI v4 on Vue 3 + Vite, no Nuxt framework. Reason: PrimeVue 5 moved to the proprietary PrimeUI License (key, eligibility thresholds, OEM question for plugin panels) — a poor fit for a distributed npm package.
- The SPA loads nothing from the internet. Reason: nodes may run on a LAN without internet.
