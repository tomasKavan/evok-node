## Lights — shape decisions

- S1: Matter semantics 1:1 — `onOff` false = Off (level kept), true = On → `onLevel` setting or last level; `level` SET = MoveToLevelWithOnOff (switches on). No ExecuteIfOff.
- S2: `onFor(seconds)` on every light (bridge maps OnWithTimedOff); `TimerRelay` stays a separate virtual device.
- S3: `startUp` setting in the device record; applied by templates at daemon start for RO/AO; DALI also mirrors it into the gear (`powerOnLevel`/`systemFailureLevel`).
- S4: B — plain SETs use the default fade; methods `moveToLevel({level, transition})`, `moveToColorTemp(...)` mirror Matter commands; onOff timing from settings.
- S5: mixing in linear light, constant brightness over CT; datasheet checked (DT6, log curve, 0.1–100 %).
- S6: `tunable-rgbw-4dali` added → `ExtendedColorLight` gets a template (memo + M3.3 to update); warm dimming left out.
- S7: ExtendedColorLight fields as proposed (XY float, CT).
